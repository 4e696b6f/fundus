# Widersprüche

Stellen, an denen sich Quellen oder Seiten widersprechen. Der Agent trägt ein,
die Person entscheidet.

```
- [[seite-a]] ↔ [[seite-b]]: worin sie sich widersprechen · beide Aussagen auf [[seite-c]] · seit [Datum] · offen
- [[seite]] ↔ module/<modulname>/<datei>: worin sie sich widersprechen · beide Aussagen auf [[seite-c]] · seit [Datum] · offen
```

Vorn stehen die beiden Seiten oder Quellen, die sich widersprechen. Hinter
„beide Aussagen auf“ steht die Seite, auf der beide Aussagen nebeneinander
stehen und die `strittig` trägt. Ist das eine der beiden vorderen Seiten,
steht sie dort noch einmal.

Die zweite Form gilt, wenn eine Quelle einer Datei in einem Modul
widerspricht. Der Agent entscheidet auch hier nicht. Die Person kann den
Widerspruch über `kontakt:` in der `MODUL.md` an das Modul melden.
